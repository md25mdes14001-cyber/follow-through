# Follow-Through

Portfolio and thesis plan of Abhimanyu Shukla (M.Des Interaction Design, IIT Hyderabad): *designing the missing step between knowing and doing in India's everyday waste*.

- `index.html`: the site (dark; a switch in the header changes theme)
- `light.html`: the same site in light mode
- `docs/`: decks, one-page case studies, posters, the thesis dossier, the research proposal and the partner brief
- `prototype/`: clickable Seva Circle and Trust Receipt prototype (sample data)

Every claim carries a label (DONE, IN PROGRESS, PLANNED, CONCEPT) and every number names its source.
